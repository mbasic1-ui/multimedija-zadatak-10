# Multimedija - Zadatak 10

Projekt vježbe za kolegij Multimedija na Fakultetu informatike u Puli (FIPU).

## Opis projekta

Web stranica za prodaju figurica i kolekcionarskih predmeta. Stranica prikazuje naslovnicu s hero sekcijom te tri kategorije proizvoda: Hit proizvodi, Nedavno dodano i Uskoro dolazi.

## Tehnologije

- **HTML5**
- **CSS3**
- **Bootstrap 5.3**

## Dizajn

Stranica je u potpunosti responzivna i prilagođava se različitim veličinama ekrana
